# 02: Отправлять уведомления в выбранную тему

## Что реализовать

Администратор выбирает тему уведомлений в супергруппе Telegram и проверяет доставку пробным сообщением.

Blocked by: [01 — Отправить первое уведомление о входе в Telegram](01-send-join-notification.md)

Status: resolved

## Критерии приёмки

- [x] `/telegram chat set <chat_id> <topic_id>` доступна консоли и `op`. Группа и тема сохраняются после перезапуска.
- [x] Уведомление о входе и `/telegram test` отправляются по одному адресу с выбранным `message_thread_id`.
- [x] Вызов настройки с одним `chat_id` сбрасывает выбранную тему. Следующие запросы идут без `message_thread_id`.
- [x] При недоступной теме мод сообщает о сбое и не отправляет сообщение в общий чат.

## Answer

Реализовано в `fdbefc9`, объединено в `ad4147c`. Команда `/telegram chat set <chat_id> [topic_id]` настраивает адрес для входов и пробных сообщений. Проверены сохранение адреса после перезапуска, сброс темы и ошибка Telegram без повторной отправки в общий чат.
