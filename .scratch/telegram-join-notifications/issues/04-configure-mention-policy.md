# 04: Переключать политику упоминаний

## Что реализовать

Администратор выбирает, кого упоминает бот. Режим применяется со следующего входа и сохраняется после перезапуска.

Blocked by: [03 — Привязать Telegram username и получать упоминания](03-link-telegram-username.md)

Status: resolved

## Критерии приёмки

- [x] Консоль и `op` меняют режим командой. Обычный игрок не может его изменить.
- [x] `all` действует по умолчанию и упоминает всех привязанных, кроме вошедшего.
- [x] `offline` упоминает только привязанных игроков, которые офлайн в момент входа, и исключает вошедшего.
- [x] `none` оставляет сообщение о входе без упоминаний. Пустой список получателей в любом режиме также сохраняет сообщение.

## Answer

Реализовано в `9e4df9d`, объединено в `7c44b6a`. Команда `/telegram mentions all|offline|none` задаёт политику. Проверены каждый режим, права, применение к следующему входу и сохранение после перезапуска. В `b5a44c0` добавлена доставка всех упоминаний несколькими частями, если они превышают ограничение Telegram.
