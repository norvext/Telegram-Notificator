# Форматирование шаблонов Telegram

Шаблоны хранятся в существующем TOML и используют небольшой набор Markdown-подобных маркеров. Мод выделяет стили до подстановки значений и передаёт Telegram готовый текст с диапазонами форматирования. Так имя сервера, ник игрока и обычная пунктуация сохраняются буквально, а шаблоны остаются читаемыми при ручном редактировании.

[Telegram Bot API](https://core.telegram.org/bots/api#messageentity)
