# 05: Пропускать уведомления при быстром перезаходе

## Что реализовать

Быстрый перезаход игрока и возвращение после быстрого штатного перезапуска не засоряют группу уведомлений.

Blocked by: [01 — Отправить первое уведомление о входе в Telegram](01-send-join-notification.md)

Status: resolved

## Критерии приёмки

- [x] При интервале по умолчанию 300 секунд вход через 299 секунд после последнего выхода того же UUID не вызывает отправку. Вход через ровно 300 секунд или при отсутствии отметки проходит фильтр.
- [x] Каждый выход обновляет отметку, даже после подавленного входа. Отметки сохраняются между запусками.
- [x] При штатной остановке сервер сохраняет время остановки как время выхода всех игроков, которые ещё онлайн. После быстрого перезапуска их входы подавляются до истечения интервала.
- [x] Консоль и `op` задают интервал в секундах, изменение действует сразу и сохраняется после перезапуска. Значение `0` отключает фильтр, отрицательное значение отклоняется.

## Answer

Реализовано в `f035a9f`, объединено в `e695667`. Команда `/telegram rejoin set <seconds>` задаёт порог. Интеграционная проверка покрывает повторные выходы, перезапуск с онлайн-игроками, сохранение настроек и отключение фильтра. Граница дополнительно проверена для 299 и 300 секунд без ожидания в реальном времени.
