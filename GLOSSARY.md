# Telegram Notificator

Уведомления о событиях выделенного сервера Minecraft в Telegram.

## Термины

**Вход игрока** — успешное подключение игрока к выделенному серверу Minecraft.

**Группа уведомлений** — группа Telegram, в которую бот отправляет уведомления.

**Тема уведомлений** — выбранная тема внутри группы уведомлений с включённым режимом форума.

**Привязка игрока** — указанный самим игроком Telegram username, связанный с его UUID в Minecraft. Один username без учёта регистра может быть привязан только к одному UUID.

**Уведомление о входе** — сообщение в группе уведомлений о том, что игрок подключился к серверу.

**Имя сервера** — отображаемое имя экземпляра выделенного сервера Minecraft в сообщениях бота.

**Уведомление о запуске** — сообщение о готовности выделенного сервера Minecraft принимать игроков. Оно может упоминать всех игроков с привязкой на этом сервере.

**Шаблон уведомления** — редактируемый текст сообщения с местами для подстановки данных о сервере, игроке и упоминаниях.
