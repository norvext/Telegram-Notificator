# 03: Привязать Telegram username и получать упоминания

## Что реализовать

Игрок управляет своей привязкой командой Minecraft. Бот упоминает привязанных игроков в уведомлении о входе.

Blocked by: [01 — Отправить первое уведомление о входе в Telegram](01-send-join-notification.md)

Status: resolved

## Критерии приёмки

- [x] Обычный игрок может создать, заменить и снять свою привязку. Сервер берёт UUID из его сессии. Привязка строится на доверии и сохраняется между запусками.
- [x] Username уникален без учёта регистра. При конфликте обе прежние привязки сохраняются.
- [x] `op` может снять чужую привязку и освободить username. Обычный игрок управляет только своей привязкой.
- [x] Бот упоминает всех привязанных игроков, онлайн и офлайн, кроме вошедшего. Вход без привязки тоже может вызвать уведомление. При пустом списке бот отправляет сообщение без упоминаний.

## Answer

Реализовано в `95d9d31`. Игрок управляет своей привязкой через `/telegram link <username>` и `/telegram unlink`. Оператор снимает привязку по Telegram username через `/telegram unlink <username>`. Проверка на выделенном сервере покрывает конфликт регистра, сохранение привязок после перезапуска и исключение вошедшего из упоминаний.
