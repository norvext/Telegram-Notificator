## Совместимость

Мод рассчитан на выделенный сервер Minecraft 1.21.1 с NeoForge 21.1.x (собран и проверен на 21.1.265) и Java 21. Мод ставится только на сервер: игрокам он не нужен, на клиенте и в одиночной игре он не загружается.

## Настройка

1. Поместите JAR мода в папку `mods/` и запустите выделенный сервер.
2. Создайте бота через [@BotFather](https://t.me/BotFather). Добавьте его в группу и разрешите отправлять сообщения.
3. В консоли выполните `telegram token set <токен>` и `telegram chat set <chat_id> [topic_id]`. Укажите отрицательный ID группы. Для доставки в тему добавьте её числовой ID.
4. Выполните `telegram test` и проверьте, что сообщение пришло в нужную группу или тему. При ошибке ответ содержит причину от Telegram, например `chat not found`.
5. `telegram status` показывает, что уже настроено, а `telegram` без аргументов — список доступных команд.

Мод хранит настройки и привязки в `config/telegramnotificator-local.toml`. При первом запуске он создаёт этот файл со всеми полями и пояснениями к ним. Файл содержит токен бота. Вводите токен в доверенной консоли с учётом того, что серверная панель может сохранять историю команд.

## Шаблоны уведомлений

Откройте `config/telegramnotificator-local.toml`. Мод добавляет отсутствующие поля при запуске. Для каждого сервера задайте своё `serverName`. Серверы могут использовать один токен бота и хранить собственные настройки и привязки.

````toml
serverName = "Survival EU"
notifyOnStartup = true
notifyOnLeave = true

joinMessage = '''
🟢 **<PlayerName>** вошёл на сервер `<ServerName>` (<Online>/<MaxPlayers>)
<TgTags>
'''

leaveMessage = '🔴 **<PlayerName>** вышел, в игре осталось <Online>'

startupMessage = '''
**<ServerName>** готов принимать игроков.
Пора играть! <TgTags>
'''

testMessage = 'Проверка доставки от `<ServerName>`'
````

- `<ServerName>`, `<Online>` (число игроков в игре) и `<MaxPlayers>` (число мест) доступны во всех шаблонах. `<PlayerName>` доступен в `joinMessage` и `leaveMessage`.
- `<TgTags>` можно поставить один раз в `joinMessage` или `startupMessage` вне форматированного фрагмента. Если упоминаний нет, отдельная строка с `<TgTags>` убирается. Если список превышает лимит сообщения, оставшиеся упоминания приходят следом.
- `**жирный**`, `_курсив_`, `__подчёркнутый__` и `~~зачёркнутый~~` задают стили Telegram. Одинарные обратные кавычки дают моноширинный фрагмент, тройные выделяют многострочный блок. Используйте стили по отдельности. Текст шаблона после подстановки без списка упоминаний должен укладываться в 4096 единиц UTF-16.

После сохранения файла выполните `telegram reload`. При ошибке чтения или проверки шаблона продолжают действовать предыдущие настройки. Тестовая отправка проверяет `testMessage` и текущую группу или тему.

Файл можно редактировать в Windows: переводы строк CRLF в сообщения не попадают.

Уведомление о запуске включено по умолчанию. Оно отправляется при готовности сервера, если бот и группа настроены, и упоминает всех привязанных игроков этого сервера независимо от режима `mentions`. Изменение `notifyOnStartup` применяется при следующем запуске.

Уведомление о выходе выключено по умолчанию. Оно отправляется без упоминаний, когда после выхода игрока истёк интервал `rejoinSeconds` и игрок не вернулся. Быстрый перезаход не создаёт ни сообщения о выходе, ни сообщения о входе. При остановке сервера сообщения о выходе не отправляются.

## Команды

В игре вводите команды с `/`, а в консоли без него.

| Команда | Кто может выполнить | Действие |
| --- | --- | --- |
| `/telegram` | Все | Показывает свою привязку и доступные команды. |
| `/telegram status` | Оператор или консоль | Показывает текущие настройки без токена. |
| `/telegram list` | Оператор или консоль | Показывает привязки игроков. |
| `/telegram link <username>` | Игрок | Сохраняет или заменяет свою привязку. Укажите имя без `@`. |
| `/telegram unlink` | Игрок | Удаляет свою привязку. |
| `/telegram unlink <username>` | Оператор или консоль | Удаляет привязку по имени Telegram. |
| `/telegram token set <токен>` | Оператор или консоль | Сохраняет токен бота. |
| `/telegram token remove` | Оператор или консоль | Удаляет токен и приостанавливает отправку. |
| `/telegram chat set <chat_id> [topic_id]` | Оператор или консоль | Задаёт группу и тему. Пропустите `topic_id`, чтобы отправлять в общий чат. |
| `/telegram mentions <all\|offline\|none>` | Оператор или консоль | Упоминает всех привязанных, только офлайн-игроков или никого. Вошедший игрок всегда исключён. По умолчанию действует `all`. |
| `/telegram rejoin set <секунды>` | Оператор или консоль | Пропускает уведомление, если игрок вернулся раньше указанного интервала. По умолчанию 300 секунд. Значение `0` отключает фильтр. |
| `/telegram test` | Оператор или консоль | Отправляет пробное сообщение без упоминаний. |
| `/telegram reload` | Оператор или консоль | Перечитывает настройки и шаблоны из файла. |
| `/telegram startup <true\|false>` | Оператор или консоль | Включает или выключает уведомление при следующем запуске сервера. |
| `/telegram leave <true\|false>` | Оператор или консоль | Включает или выключает уведомления о выходе игроков. |

## Сборка и проверка

Нужен JDK 21. `./gradlew build` собирает `build/libs/telegramnotificator-1.21.1-<версия>.jar` и запускает модульные тесты чистой логики из пакета `core`. Сценарии в `tests/` поднимают выделенный сервер с заменителем Telegram и подключают к нему игрока по протоколу 1.21.1, например `python tests/telegram_server.py`. Они работают в Linux и Windows.
