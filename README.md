# Telegram Notificator

**Автор** norvext · **Minecraft** 26.3 · **NeoForge** 26.3.0.101 · **Язык** Java 25

[English documentation](docs/README.en.md)

Мод отправляет уведомления о входе игроков в группу или тему Telegram. Игроки могут привязать свой Telegram username, чтобы бот упоминал их в уведомлениях.

## Совместимость

Мод рассчитан на выделенный сервер Minecraft 26.3 с NeoForge 26.3.0.101 и Java 25. Игроки могут подключаться с обычного клиента.

## Настройка

1. Поместите JAR мода в папку `mods/` и запустите выделенный сервер.
2. Создайте бота через [@BotFather](https://t.me/BotFather). Добавьте его в группу и разрешите отправлять сообщения.
3. В консоли выполните `telegram token set <токен>` и `telegram chat set <chat_id> [topic_id]`. Укажите отрицательный ID группы. Для доставки в тему добавьте её числовой ID.
4. Выполните `telegram test` и проверьте, что сообщение пришло в нужную группу или тему.

Мод хранит настройки и привязки в `config/telegramnotificator-local.toml`. Файл содержит токен бота. Вводите токен в доверенной консоли с учётом того, что серверная панель может сохранять историю команд.

## Команды

В игре вводите команды с `/`, а в консоли без него.

| Команда | Кто может выполнить | Действие |
| --- | --- | --- |
| `/telegram link <username>` | Игрок | Сохраняет или заменяет свою привязку. Укажите имя без `@`. |
| `/telegram unlink` | Игрок | Удаляет свою привязку. |
| `/telegram unlink <username>` | Оператор или консоль | Удаляет привязку по имени Telegram. |
| `/telegram token set <токен>` | Оператор или консоль | Сохраняет токен бота. |
| `/telegram token remove` | Оператор или консоль | Удаляет токен и приостанавливает отправку. |
| `/telegram chat set <chat_id> [topic_id]` | Оператор или консоль | Задаёт группу и тему. Пропустите `topic_id`, чтобы отправлять в общий чат. |
| `/telegram mentions <all\|offline\|none>` | Оператор или консоль | Упоминает всех привязанных, только офлайн-игроков или никого. Вошедший игрок всегда исключён. По умолчанию действует `all`. |
| `/telegram rejoin set <секунды>` | Оператор или консоль | Пропускает уведомление, если игрок вернулся раньше указанного интервала. По умолчанию 300 секунд. Значение `0` отключает фильтр. |
| `/telegram test` | Оператор или консоль | Отправляет пробное сообщение без упоминаний. |
