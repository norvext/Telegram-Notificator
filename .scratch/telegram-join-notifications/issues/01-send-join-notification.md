# 01: Отправить первое уведомление о входе в Telegram

## Что реализовать

Администратор настраивает бота на выделенном сервере и проверяет доставку. После успешного входа игрока бот отправляет сообщение в обычную группу Telegram.

Blocked by: None (can start immediately)

Status: resolved

## Критерии приёмки

- [x] Мод работает на выделенном сервере, клиент без мода подключается, а одиночная игра и LAN не отправляют уведомления.
- [x] Консоль и игрок с `op` могут задать и заменить токен через `/telegram token set <токен>` и настроить группу через `/telegram chat set <chat_id>`. Обычный игрок не может выполнить эти команды. Настройки действуют сразу и сохраняются после перезапуска.
- [x] `/telegram token remove` доступна консоли и `op`, принимает только вызов без аргументов и удаляет сохранённый токен. При повторном вызове сообщение «Токен не задан» видит только вызывающий.
- [x] `/telegram test` доступна консоли и `op`, отправляет пробное сообщение без упоминаний и сообщает результат вызывающему.
- [x] Успешный вход любого игрока отправляет сообщение в настроенную группу. При отсутствии токена или группы запрос не выполняется.
- [x] Отправка асинхронная, с таймаутом и одной попыткой. При сбое игрок может войти, причина доступна в журнале, токен отсутствует в ответах и журналах мода.

## Answer

Реализовано в `cd2a47b`. Интеграционная проверка запускает выделенный сервер NeoForge, подключает клиент по ванильному протоколу и проверяет команды, доставку и таймаут через локальный заменитель Telegram. Запуск отдельного dev-клиента подтвердил, что вход в одиночный мир не отправляет запрос. LAN использует ту же клиентскую точку входа; подключение гостя по LAN отдельно не проверялось.
