# Настраиваемые уведомления Telegram

- Шаблоны входа, запуска и пробной отправки, имя сервера и переключатель запуска хранятся в `config/telegramnotificator-local.toml`. При обновлении дополняются только отсутствующие поля.
- Шаблоны поддерживают несколько строк и Markdown-подобные стили. `<ServerName>` доступен во всех шаблонах, `<PlayerName>` доступен для входа, `<TgTags>` доступен для входа и запуска.
- Консоль и операторы могут перечитать файл командой `/telegram reload`. Ошибка чтения или проверки шаблона оставляет действующие настройки. Административные команды не перезаписывают правки, ожидающие перечитывания.
- `notifyOnStartup` включён по умолчанию. Консоль и операторы могут сохранить новое значение через `/telegram startup true` или `/telegram startup false`.
- При готовности сервера к приёму игроков отправляется одно уведомление о запуске, если задана группа и токен. В шаблон запуска подставляются все привязки данного сервера независимо от политики упоминаний при входе. Список, который превышает лимит Telegram, отправляется несколькими сообщениями.
- Настройки и привязки принадлежат отдельному экземпляру. Несколько экземпляров могут отправлять через один токен и отличаться именами серверов.
- Консоль фиксирует успешную отправку каждой части и вид события без текста сообщения и токена.
